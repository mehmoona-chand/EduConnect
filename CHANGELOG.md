## [1.0.0] — 2026-06-15 🎉 Initial Release

### Added
- **Visitor Portal** — homepage with tutor listings and course browsing
- **Tutor Dashboard** — tutors can manage courses, view inquiries, update profile
- **Admin Panel** — full CRUD for users, tutors, courses, and inquiries
- **Session-based authentication** — separate secure login for Admin and Tutor roles
- **Inquiry system** — visitors can submit inquiries to tutors directly
- **Responsive UI** — built with Bootstrap 5 and AdminLTE 3
- **Database schema** — `otps_db.sql` with all tables and seed data
- **PHP OOP structure** — `DBConnection`, `Login`, `Master`, `Users`, `SystemSettings` classes
- **README.md** — full setup guide, tech stack, project structure, and credentials
